## OmniTool Note 소개

OmniTool Note는 PC 프로그램 OmniTool의 메모, 일정, D-day, 포스트잇을 안드로이드 폰에서 보고 고치는 앱입니다. 사용자의 구글 드라이브에 있는 OmniTool 동기화 파일을 읽고 써서 PC와 내용을 맞춥니다.

## 개인정보처리방침

최종 수정일: 2026년 11월 3일

### 사용하는 구글 데이터

앱은 구글 로그인으로 **구글 드라이브 파일 보기, 수정, 생성, 삭제 권한**(`https://www.googleapis.com/auth/drive`)을 받습니다. PC 프로그램이 만든 파일은 더 좁은 권한으로는 앱에 보이지 않기 때문에 이 권한을 사용합니다.

앱은 이 권한을 다음 용도로만 사용합니다.

- 드라이브에서 이름이 `omnitool_backup.zip`인 파일을 찾습니다. 다른 파일은 읽거나 고치지 않습니다.
- 그 파일을 내려받아 메모, 일정, D-day, 포스트잇을 화면에 보여 줍니다.
- 사용자가 저장하거나 알림창에서 포스트잇을 보내면 고친 내용을 같은 파일에 올립니다. 파일 안의 다른 항목은 내용을 바꾸지 않습니다.

### 폰에 저장하는 정보

다음 정보는 사용자의 폰 안에 있는 앱 전용 저장 공간에만 저장합니다.

- 마지막으로 내려받은 동기화 파일 전체. 인터넷이 없을 때 내용을 보여 주는 데 씁니다. 이 파일에는 네 항목 외에 OmniTool의 다른 도구 데이터도 들어 있습니다.
- 드라이브에 올리기 전 파일의 사본 최대 10개
- 아직 보내지 못한 알림창 포스트잇 글
- 테마와 알림 같은 앱 설정

### 수집과 공유

앱은 별도의 서버를 사용하지 않으며, 개발자는 사용자의 데이터를 받아 보거나 보관하지 않습니다. 데이터는 사용자의 폰과 구글 서버 사이에서만 오갑니다. 광고나 분석 도구도 쓰지 않으며, 구글 사용자 데이터를 제3자에게 판매하거나 전달하지 않습니다.

구글 API에서 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 따릅니다.

### 데이터 삭제와 권한 철회

- 앱을 삭제하면 폰에 저장된 앱 데이터가 함께 삭제됩니다.
- [구글 계정의 타사 연결 관리](https://myaccount.google.com/connections)에서 앱의 드라이브 권한을 언제든지 철회할 수 있습니다.
- 드라이브의 파일은 사용자의 구글 드라이브에 그대로 남으며, 드라이브에서 직접 삭제할 수 있습니다.
