작동 환경: Windows 10 이상 64비트

## 새 기능
- 별도 비교 창에서도 복사: 변천사·라인 이력·내용 검색·즉석 파일 비교 창에서도 여러 줄을 끌어 선택해 복사할 수 있습니다. 우클릭 메뉴와 Ctrl+C 모두 메인 화면과 똑같이 동작합니다.

## 버그 수정
- 비교 화면에서 한글 주석이 깨져 보이던 문제를 바로잡았습니다. 이제 파일마다 저장 방식을 알아서 알아보므로, 한 프로젝트에 서로 다른 방식으로 저장된 파일이 섞여 있어도 모두 제대로 보입니다. (내용은 그대로이고 저장 방식만 바꾼 파일은 이제 '일치'로 표시됩니다.)
- 왼쪽을 클릭하고 Ctrl+C를 눌러도 항상 오른쪽만 복사되던 문제를 바로잡았습니다. 이제 마지막으로 누른 쪽이 복사되며, 지금 어느 쪽이 복사되는지 위쪽 A·B 표시에 강조되어 나옵니다.
- 코드 자동 정리에서 한글이 섞인 줄만 주석 위치가 어긋나던 문제를 바로잡았습니다. 한글과 한자가 두 칸을 차지하는 것을 반영해 세로 정렬을 계산합니다.

## 개선
- 실시간 연동의 반응이 빨라졌습니다. 변경을 감지한 뒤 기다리는 시간이 약 0.5초로 줄었고, 파일이 많아 읽는 데 오래 걸리는 프로젝트에서는 부담이 커지지 않도록 스스로 간격을 늘립니다.
- 실시간 연동 중 파일을 저장하는 순간 그 파일이 잠깐 '삭제됨'으로 깜빡이던 현상을 없앴습니다.
- 실시간 연동을 켠 채 다른 프로젝트를 보다가 돌아오면 다시 이어집니다. 예전에는 프로젝트를 옮기면 꺼졌습니다. 프로그램을 끄면 해제됩니다.
