TeamBoard(이하 "앱")는 사용자의 개인정보를 아래와 같이 다룹니다.

## 1. 받는 정보

앱은 구글 로그인을 통해 다음 정보와 권한만 받습니다.

- 구글 계정 메일 주소: 팀원 사이에서 사용자를 구분하는 데 씁니다.
- 구글 스프레드시트 읽기 · 쓰기 권한: 앱이 만든 시트와 사용자가 연결한 시트에 프로젝트 · 티켓 · 일정 기록을 저장하고 불러오는 데 씁니다.

## 2. 저장 위치

- 기록은 사용자 본인의 구글 드라이브에 있는 시트에 저장됩니다. 팀 시트는 사용자가 직접 공유한 팀원만 볼 수 있습니다.
- 로그인 정보와 앱 설정은 사용자 PC 안의 앱 데이터 폴더에만 저장됩니다.
- 앱 개발자는 별도 서버를 운영하지 않으며, 사용자의 기록이나 계정 정보를 받거나 볼 수 없습니다.

## 3. 제3자 제공

앱은 사용자 정보를 제3자에게 팔거나 넘기지 않습니다.
다만 사용자가 직접 Claude(MCP)를 앱에 연결한 경우, 사용자가 요청한 티켓 정보가 사용자의 Claude 앱으로 전달됩니다. 이 정보는 사용자가 쓰는 Claude 서비스의 정책을 따릅니다.

## 4. Google API 데이터 사용

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 따릅니다.

## 5. 삭제와 접근 취소

- 앱의 로그아웃을 누르면 PC에 저장된 로그인 정보가 지워집니다.
- 시트에 저장된 기록은 사용자가 구글 드라이브에서 직접 지울 수 있습니다.
- 앱의 구글 계정 접근 권한은 [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions)에서 언제든 취소할 수 있습니다.
