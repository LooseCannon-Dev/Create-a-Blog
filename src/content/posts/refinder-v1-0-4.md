Windows 10 이상 64비트에서 씁니다.

- 리파인더에서 직접 고친 문서를 눈으로 볼 수 있습니다.
  - 기록 탭에서 저장한 줄은 '사용자가 고침', 여기서 새로 만든 문서는 '사용자가 만듦' 으로 적힙니다.
  - 그래프에서 직접 고친 문서는 점 왼쪽 위에 파란 작은 점이 붙습니다. Claude 가 고친 문서의 점(오른쪽 위)과 함께 보여, 둘 다 고친 문서는 점이 둘입니다. 범례에 수가, 말풍선에 마지막으로 고친 때가 나옵니다.
  - 그래프 설정 판에서 끔 · 오늘 · 7일 · 전체 가운데 고릅니다(처음에는 7일). Claude 표시와 따로 고릅니다.
- 하단 상태 줄 맨 오른쪽에 지금 쓰고 있는 버전이 보입니다.
- 앱 안에서 업데이트를 누르면 프로그램이 닫힌 뒤 설치가 시작되지 않고 넘어가던 문제를 고쳤습니다. 이 때문에 '새 테스트판' 단추가 계속 남아 있었습니다.
- 업데이트가 끝나면 리파인더가 다시 열리고, 다른 창 뒤에 가려지지 않게 앞으로 올라옵니다. 설치가 실패해도 쓰던 판으로 다시 열리고 반영되지 않았다고 알려 줍니다.
- Claude Code 를 켜 둔 채로 설치하면 '액세스가 거부되었습니다' 로 설치가 멈추던 문제를 고쳤습니다.

※ 이번 고침은 이 판을 설치한 다음부터 적용됩니다. 지금 판에서 앱 안 업데이트가 넘어가면 한 번 더 눌러 보시거나, 아래 설치본을 받아 직접 설치해 주세요.
