회사에서 잠깐 동영상을 보거나 쇼핑몰을 둘러보다 보면, 탭 목록에 떠 있는 사이트 이름이 신경 쓰입니다.
누가 뒤를 지나갈 때 탭을 하나하나 닫자니 늦고, 그대로 두자니 다 보입니다.

**Tab Customizer는 이럴 때 쓰는 Chrome 확장 프로그램입니다.**

- **딴짓 탭을 업무 문서처럼 보이게** — 동영상 탭은 '주간 업무 보고', 쇼핑 탭은 '거래처 견적서'로
- **누가 다가오면 Ctrl+Q 한 번** — 딴짓 탭 묶음이 접히고 업무 문서 화면으로 바로 넘어갑니다

- 지원 환경: PC용 Chrome
- 내려받기: [릴리스 페이지](https://github.com/LooseCannon-Dev/TabCustomizer-releases/releases/latest)

![설정 전에는 동영상·쇼핑 탭 이름이 그대로 보이고, 설정 후에는 '주간 업무 보고'·'거래처 견적서'로 보인다](/Create-a-Blog/images/tab-customizer/hide_01_before_after.png)

*위: 설정 전 / 아래: 설정 후 — 같은 탭인데 업무 문서처럼 보입니다.*

## 1. 딴짓 탭을 업무 문서처럼 — 탭 이름·아이콘 바꾸기

사이트마다 탭에 보이는 **이름**과 **아이콘**을 정해 둘 수 있습니다. 한 번 정해 두면 그 사이트를 열 때마다 자동으로 적용됩니다.

![동영상 사이트를 보고 있지만 탭에는 '주간 업무 보고'와 차트 아이콘만 보인다](/Create-a-Blog/images/tab-customizer/hide_02_video_disguised.png)

*실제로는 동영상을 보는 중이지만, 탭에는 '주간 업무 보고'만 보입니다.*

- 툴바의 확장 아이콘을 누르면 **지금 보고 있는 사이트**를 바로 설정할 수 있습니다.
- 아이콘은 업무·문서 분류를 포함한 360여 개 이모지 중에서 고릅니다.
- 이름을 바꿔도 안 읽은 알림 수 "(3)"은 그대로 보입니다.

![팝업 화면. 적용할 사이트, 탭 이름 '주간 업무 보고', 아이콘 고르기, 탭 정리 칸이 있다](/Create-a-Blog/images/tab-customizer/hide_03_popup.png)

## 2. 더 감쪽같이 — 내 아이콘 (V1.0.1)

이모지로는 티가 난다면, **표·문서 프로그램처럼 보이는 그림 파일을 직접 올려** 탭 아이콘으로 쓸 수 있습니다.

![표 그림을 올려 동영상 탭을 '4분기 실적 정리' 문서처럼 꾸민 모습과 '내 아이콘' 관리 화면](/Create-a-Blog/images/tab-customizer/hide_04_my_icon.png)

- PNG·JPG·GIF·WebP·SVG·ICO 파일을 올리면 탭 아이콘 크기로 알아서 줄여 줍니다.
- 한 번 올린 그림은 여러 사이트에서 같이 쓸 수 있습니다.

## 3. 북마크에는 가짜 이름이 남지 않게 (V1.0.1)

꾸민 탭을 북마크해도 **페이지의 원래 이름**으로 저장됩니다. 나중에 북마크 목록을 볼 때 '주간 업무 보고'가 잔뜩 쌓여 헷갈릴 일이 없습니다.

![탭에는 '주간 업무 보고'로 보이지만 북마크바에는 원래 영상 제목으로 저장된 모습](/Create-a-Blog/images/tab-customizer/hide_05_bookmark.png)

## 4. 딴짓 탭을 닫으면 업무 화면으로 (V1.0.2)

딴짓 탭을 '참고자료' 같은 **탭 그룹**에 모아 두세요. 그룹 안에서 보던 탭을 닫으면, Chrome이 원래 하던 것처럼 **옆의 딴짓 탭을 보여 주는 대신** 그룹이 접히고 업무 탭으로 넘어갑니다.

![그룹 안의 동영상 탭을 닫으면 그룹이 접히고 업무 문서 탭으로 넘어간다](/Create-a-Blog/images/tab-customizer/hide_06_close_collapse.png)

- 그룹에 남은 탭은 닫히지 않습니다. 그룹 이름표를 누르면 다시 펼쳐집니다.
- 관리 페이지에서 켜고 끄며, 그룹마다 따로 정할 수 있습니다.

## 5. 누가 다가오면 Ctrl+Q (V1.0.3)

가장 많이 쓰게 될 기능입니다. **Ctrl+Q 한 번**이면 보던 딴짓 그룹이 접히고, 그룹 밖에서 마지막으로 보던 업무 탭으로 바로 넘어갑니다.

![동영상을 보던 중 Ctrl+Q를 누르자 그룹이 접히고 업무 문서 화면이 나온 모습](/Create-a-Blog/images/tab-customizer/hide_07_ctrl_q.png)

*Ctrl+W(탭 닫기) 바로 옆 키라 손이 금방 익습니다.*

- 그룹 밖에서 누르면 창의 그룹을 모두 접고, 다시 누르면 모두 펼칩니다.
- 주소창이나 새 탭을 보고 있을 때도 동작합니다.
- 키가 마음에 들지 않으면 바꿀 수 있습니다.
  - Chrome 단축키 설정에서 Ctrl+Q 를 다른 키로 바꾸거나
  - 관리 페이지에서 원하는 키 조합을 직접 눌러 확장 단축키를 하나 더 정할 수 있습니다 (Ctrl·Alt·Shift·Win 자유 조합, Chrome 기본 단축키는 제외)

## 그 밖의 기능

### 탭 자동 정리 — 그룹으로 묶기 / 고정

- **그룹:** 그룹 이름과 색을 정해 두면, 그 사이트를 열 때 자동으로 같은 탭 그룹에 묶입니다. 딴짓 탭을 한 그룹에 모아 두는 데 씁니다.
- **고정:** 늘 켜 두는 사이트(음악, 메신저 등)는 열 때마다 자동으로 탭이 고정됩니다.

### 사이트 차단 — 원치 않는 탭 자동으로 닫기

- 등록한 사이트가 **새 탭이나 팝업 창으로 열리면** 바로 닫습니다.
- **보던 탭이 광고 사이트로 넘어가면** 이전 페이지로 되돌립니다.
- 팝업의 "이 사이트 차단" 버튼, 관리 페이지 주소 입력, 최근 닫힌 탭 목록에서 등록할 수 있습니다.

### 옴니툴 연동

- 옴니툴에 등록한 차단 목록을 Chrome에서도 그대로 사용합니다. 옴니툴에서 바꾸면 바로 반영됩니다.

## 한곳에서 관리하고, 백업까지

![관리 페이지의 탭 꾸미기 규칙 표, 보던 탭을 닫으면 그룹 접기 설정, 그룹 접기 단축키 설정](/Create-a-Blog/images/tab-customizer/hide_08_options.png)

- 규칙·그룹 접기·단축키·차단 목록을 관리 페이지 한곳에서 고칩니다.
- **꾸미기 ON/OFF:** 전체를 한 번에 켜고 끌 수 있고, 사이트별로도 켜고 끌 수 있습니다.
- **백업·복원:** 규칙·올린 그림·설정을 파일 하나로 저장해 두고 다른 PC로 옮길 수 있습니다.

## 설치 방법

Tab Customizer는 Chrome 웹 스토어가 아닌 파일로 배포합니다.

1. 아래 **다운로드** 링크에서 압축 파일을 받아 계속 둘 위치에 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 `TabCustomizer` 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **Tab Customizer** 옆의 핀을 눌러 고정해 두면 편리합니다.

> 업데이트할 때는 새 파일로 폴더를 덮어쓴 뒤, `chrome://extensions`에서 **새로고침(↻)** 버튼을 눌러 주세요. 업데이트 전에 관리 페이지에서 **백업 파일 저장**을 해 두면 더 안전합니다.
