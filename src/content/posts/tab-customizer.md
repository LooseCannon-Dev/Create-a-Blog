탭을 여러 개 띄워 두다 보면 어떤 탭이 무엇인지 한눈에 알아보기 어렵습니다. 원치 않는 광고 창이 뜨면 일일이 닫아야 하는 것도 번거롭습니다.
**Tab Customizer**는 이 두 가지를 해결하는 Chrome 확장 프로그램입니다.

- 지원 환경: PC용 Chrome
- 내려받기: [릴리스 페이지](https://github.com/LooseCannon-Dev/TabCustomizer-releases/releases/latest)

![설치 전 탭 모습. YouTube, NAVER, GitHub, Google 탭이 원래 이름과 아이콘으로 나란히 있다](/Create-a-Blog/images/tab-customizer/01_tabs_before.png)

![Tab Customizer 적용 후 탭 모습. 음악 탭은 고정되고, 포털 탭은 초록 아이콘으로, 내 저장소와 검색 탭은 '작업' 그룹으로 묶였다](/Create-a-Blog/images/tab-customizer/02_tabs_after.png)

*위: 원래 탭 / 아래: Tab Customizer 적용 후 — 이름과 아이콘이 바뀌고, 작업 탭은 그룹으로 묶이고, 음악 탭은 고정되었습니다.*

## 이런 분께 추천합니다

- 비슷하게 생긴 탭이 많아 원하는 탭을 찾느라 헤매는 분
- 자주 쓰는 사이트를 늘 같은 자리, 같은 모습으로 두고 싶은 분
- 클릭 한 번에 광고 창이 줄줄이 뜨는 사이트 때문에 지친 분
- 옴니툴로 차단 목록을 관리하고 있고, Chrome에도 그대로 적용하고 싶은 분

## 탭 이름·아이콘 바꾸기

사이트마다 탭에 보이는 **이름**과 **아이콘**을 원하는 대로 정할 수 있습니다.

- **아이콘:** 업무·소통·쇼핑·음식 등 9개 분류, 360여 개의 이모지 중에서 고릅니다. **자동**을 누르면 다른 사이트와 겹치지 않는 아이콘을 골라 줍니다.
- **이름:** 직접 입력하거나 **자동**을 눌러 주소로 이름을 만듭니다. 예를 들어 mail.google.com은 "Google Mail"이 됩니다.
- **알림 숫자 유지:** 이름을 바꿔도 안 읽은 알림 수는 그대로 보입니다. 예를 들어 "(3) YouTube"는 "(3) 음악"으로 보입니다.
- 한 번 정해 두면 그 사이트의 모든 하위 주소에 적용됩니다. 브라우저를 다시 켜도 그대로 유지됩니다.

![팝업 화면. 적용할 사이트, 탭 이름, 아이콘 고르기, 탭 정리(없음·그룹·고정) 칸이 있다](/Create-a-Blog/images/tab-customizer/03_popup_light.png)

*툴바 아이콘을 누르면 지금 보고 있는 사이트를 바로 설정할 수 있습니다.*

## 탭 자동 정리 — 그룹으로 묶기 / 고정

사이트마다 탭을 어떻게 둘지도 정할 수 있습니다.

- **그룹:** 그룹 이름과 색을 정해 두면, 그 사이트를 열 때 자동으로 같은 탭 그룹에 묶입니다. 예를 들어 "작업" 그룹에 GitHub와 Google을 함께 넣을 수 있습니다.
- **고정:** 늘 켜 두는 사이트(음악, 메신저 등)는 열 때마다 자동으로 탭이 고정됩니다.

## 사이트 차단 — 원치 않는 탭 자동으로 닫기

등록한 사이트가 열리면 확장이 알아서 처리합니다.

- **새 탭이나 팝업 창으로 열리면** 바로 닫습니다.
- **보던 탭이 광고 사이트로 넘어가면** 탭을 닫지 않고 **이전 페이지로 되돌립니다.**
- 내가 직접 연 탭이 아니어도, 모든 창의 모든 탭에 적용됩니다.
- 등록은 세 가지 방법으로 할 수 있습니다.
  - 팝업의 **"이 사이트 차단"** 버튼
  - 관리 페이지에 주소 입력
  - **최근 닫힌 탭 목록**에서 고르기. 방금 닫은 광고 창 주소를 몰라도 됩니다.

## 옴니툴 연동

옴니툴에 등록한 사이트 차단 목록을 Chrome에서도 그대로 사용할 수 있습니다.

- 옴니툴에서 차단 사이트를 추가·삭제·수정하면 **Chrome에 바로 반영**됩니다.
- Chrome이 꺼져 있는 동안 바뀐 내용은 **Chrome을 켤 때** 받아옵니다.
- 옴니툴은 관리 페이지의 **"옴니툴 다운로드"** 버튼에서 받을 수 있습니다.

## 한곳에서 관리하고, 백업까지

![관리 페이지. 탭 꾸미기 규칙 4개, 차단할 사이트 3개, 옴니툴 차단 목록(연결됨), 최근 닫힌 탭에서 등록, 백업·복원 칸이 차례로 있다](/Create-a-Blog/images/tab-customizer/04_options_light.png)

- 관리 페이지에서 모든 규칙과 차단 목록을 한눈에 보고 고칠 수 있습니다.
- **꾸미기·차단 ON/OFF:** 전체를 한 번에 켜고 끌 수 있고, 사이트별로도 켜고 끌 수 있습니다. 꺼도 설정은 지워지지 않습니다.
- **백업·복원:** 설정을 파일 하나로 저장해 두고, 다시 설치하거나 다른 PC로 옮길 때 그대로 불러올 수 있습니다.
- **다크 모드:** 시스템 테마에 맞춰 밝은 화면과 어두운 화면이 자동으로 바뀝니다.

![관리 페이지 다크 모드](/Create-a-Blog/images/tab-customizer/04_options_dark.png)

## 설치 방법

Tab Customizer는 Chrome 웹 스토어가 아닌 파일로 배포합니다. 아래 순서대로 설치해 주세요.

1. 아래 **다운로드** 링크(GitHub 릴리스)에서 압축 파일을 받아 원하는 위치에 압축을 풉니다.
   - 압축을 푼 폴더를 지우거나 옮기면 확장이 동작하지 않으니, 계속 둘 위치에 풀어 주세요.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 `TabCustomizer` 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **Tab Customizer** 옆의 핀을 눌러 고정해 두면 편리합니다.

> 업데이트할 때는 새 파일로 폴더를 덮어쓴 뒤, `chrome://extensions`에서 Tab Customizer의 **새로고침(↻)** 버튼을 눌러 주세요. 업데이트 전에 관리 페이지에서 **백업 파일 저장**을 해 두면 더 안전합니다.
