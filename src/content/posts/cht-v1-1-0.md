작동 환경: Windows 10 이상 64비트

## 새 기능
- 종류별 보기: 변경된 파일 목록 아래의 추가·변경·삭제·이동 요약을 누르면 그 종류의 파일만 볼 수 있습니다. 같은 항목을 다시 누르면 전체로 돌아옵니다.
- 첫 차이로 자동 이동: 목록에서 다른 파일을 고르면 첫 번째 차이가 있는 곳으로 화면이 자동으로 옮겨 갑니다. 차이가 없으면 맨 위를 보여 줍니다. 코드 자동 정리 미리보기에서도 똑같이 동작합니다.

## 버그 수정
- 좌우 내용이 같은데도 변경된 파일로 표시되던 문제를 바로잡았습니다. 줄바꿈 방식이나 파일 앞부분의 보이지 않는 표식만 다른 경우로, 이제 일치로 표시됩니다.
- 어두운 테마에서 마우스를 올렸을 때 나오는 설명 글이 배경에 묻혀 보이지 않던 문제를 바로잡았습니다.

## 개선
- 어두운 테마에서 운영체제 기본 색이 그대로 드러나던 곳(닫기·최대화 같은 아이콘 버튼, 설정의 선택 항목, 목록에서 선택한 줄의 색)을 프로그램 테마에 맞게 정리했습니다.
- 폴더 필터로 감춘 폴더는 아래 요약 숫자에서도 빠져, 숫자와 실제 목록이 어긋나지 않습니다.
- 설치 프로그램 목록에 표시되는 게시자 이름을 정리했습니다.
