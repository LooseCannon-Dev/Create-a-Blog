작동 환경: Windows 10 이상 64비트

## 새 기능
- **한국어 / 영어 전환** — 설정에서 언어를 고르면 재시작 없이 즉시 바뀝니다.
- **설치 시 자동 실행 옵션** — "Windows 시작 시 자동 실행"을 설치 마법사에서 선택할 수 있습니다.
- **포터블(무설치) 버전** — 압축을 풀어 바로 실행할 수 있는 버전을 함께 제공합니다.
- **자동 업데이트** — 새 버전이 나오면 확인 후 내려받아 설치합니다.

## 개선
- 비교 뷰의 세로 미니맵을 변경 파일 목록 옆으로 옮겨 위치를 개선했습니다.
