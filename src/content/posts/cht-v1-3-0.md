작동 환경: Windows 10 이상 64비트

## 새 기능
- **AI 도구와 연결할 수 있습니다(MCP).** Claude Code · Codex · Gemini 같은 AI 도구에 코히트를 연결하면, "이거 고쳐 주고 코히트 기록도 남겨 줘"라고 할 때 AI가 고치기 직전과 직후에 기록을 남깁니다.
  - 작업 후 기록에는 AI가 무엇을 왜 고쳤는지 적은 메모와, 코히트가 직접 계산한 바꾼 파일 목록이 붙습니다.
  - AI가 남긴 기록은 타임라인에 'AI' 칩으로 보이고, 칩에 마우스를 올리면 어느 AI가 남겼는지 나옵니다.
  - AI가 기록 목록 · 바뀐 파일 · 파일 비교 · 줄마다 들어온 시점 · 내용 검색을 코히트에서 바로 조회할 수 있습니다.
  - 코히트가 꺼져 있으면 AI가 부를 때 트레이로 조용히 켜집니다.
- **설정에 'AI 연동' 묶음을 더했습니다.** AI 도구마다 연결 · 끊기 단추가 있고, 연결 상태를 보여 줍니다. 연결하거나 끊기 전에 원래 설정 파일을 사본으로 남깁니다.
- **시점 복원 · 파일 되돌리기 · 기록 정리 · 백업 가져오기는 'AI 위험 작업 허용'을 켜야 AI가 요청할 수 있습니다.** 켜도 요청마다 코히트 창에 확인 창이 뜨고, 직접 눌러야만 실행됩니다. 3분 안에 누르지 않으면 취소되고 아무것도 바뀌지 않습니다.
  - 복원과 되돌리기는 실행 전에 지금 상태를 기록으로 남깁니다.
  - 기록 정리는 기록을 '오래된 기록'으로 옮기기만 하고 지우지 않습니다.
  - 백업 가져오기는 실행 전에 지금 기록 저장소를 따로 복사해 둡니다.

## 개선
- 코히트를 제거하면 AI 도구에 등록해 둔 코히트 연결도 함께 지웁니다.
- 코히트를 다른 폴더로 옮기면, 다음에 켤 때 AI 도구의 연결을 새 위치로 다시 등록합니다.
