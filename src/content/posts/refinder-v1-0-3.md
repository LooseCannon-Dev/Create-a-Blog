Windows 10 이상 64비트에서 씁니다.

- Claude 가 문서를 고치기 전에, 사용자가 리파인더에서 직접 고친 문서와 사용자가 되돌린 Claude 의 고침을 물어볼 수 있습니다. 되돌린 고침은 그때 사용자가 한 말과 없어진 줄까지 함께 알려 주어, 같은 고침을 다시 하지 않게 합니다.
- 기록 탭에서 'Claude가 고침' 을 비교하면, 그 고침 바로 앞에 사용자가 한 말이 비교 화면 옆에 보입니다.
- Claude 메모리의 MEMORY.md 를 열면 Claude 에게 전달되지 않는 뒤쪽을 노란 띠로 칠하고, 상태 줄에 지금 몇 줄 · 몇 글자인지 한도와 함께 보입니다. Claude 는 세션을 시작할 때 이 파일의 앞 200줄 또는 앞 25,000자까지만 읽습니다.
- 형식 검사의 'Claude 메모리' 묶음이 MEMORY.md 를 위 한도로 봅니다. 예전의 크기 상한 규칙은 그대로 두었으면 저절로 바뀝니다.
- 관리 화면에 'Claude' 탭을 더했습니다.
  - 세션 시작에 받는 글: Claude 가 세션을 시작할 때 받는 규칙 파일과 메모리 목차를 받는 모양 그대로 한 화면에 보입니다.
  - 읽힌 횟수: 최근 30일 동안 Claude 가 문서마다 몇 번 열었는지 세고, 한 번도 안 읽힌 문서를 모아 보입니다.
  - 재발: 지적을 받아 만든 규칙마다 그 뒤 같은 지적이 다시 나왔는지 셉니다. 살필 낱말을 직접 더하거나 뺄 수 있습니다.
- 낡은 기록 찾기에서 문서에 적힌 버전 번호(V1.2.3)를 실제로 나온 번호와 견줍니다. GitHub 릴리스 저장소나 코드 폴더의 태그를 골라 켭니다.
- 그래프 설정 판에 '보관함 타임랩스' 를 더했습니다. 문서가 생긴 차례대로 그래프가 자라는 모습을 재생합니다.
- Claude 가 하위 작업으로 고친 문서도 'Claude가 고침' 으로 알아봅니다. 이 때문에 기록 탭에 뜨던 '읽지 못한 형식' 알림이 사라집니다.
